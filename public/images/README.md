# Portfolio Images Directory

You can place your photos and project screenshots here. The portfolio automatically loads and displays them if they are placed in this directory:

- `profile.jpg` - Hero section profile photo (Recommended: 600x600 px or 800x800 px, 1:1 square)
- `about-profile.jpg` - About section photo (Recommended: 600x700 px, 4:5 portrait)
- `project-travelsync.jpg` - TravelSync project card screenshot (Recommended: 1200x750 px, 16:10)
- `project-youtube.jpg` - YouTube Clone project card screenshot (Recommended: 1200x750 px, 16:10)
- `project-shoppyglobe.jpg` - ShoppyGlobe project card screenshot (Recommended: 1200x750 px, 16:10)
- `project-oauth-search.jpg` - MERN OAuth Image Search card screenshot (Recommended: 1200x750 px, 16:10)
